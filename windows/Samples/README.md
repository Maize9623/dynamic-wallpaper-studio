# Optional starter wallpaper

The public source repository does not include demo video or poster media because
their redistribution rights are separate from the application source license.
The app works normally without starter media: import your own video after launch.

For a private build, these optional file names are recognized:

- `StarterWallpaper.mp4`
- `StarterPoster.jpg`

Only use media that you own or have permission to redistribute. Files placed in
this directory are copied into the published application by the project file.
