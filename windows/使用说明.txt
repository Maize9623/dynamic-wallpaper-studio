动态壁纸工作室 · Windows x64 便携兼容版 1.0.4
========================================

系统要求
--------
Windows 10 22H2 或 Windows 11，64 位 x86 电脑。
无需安装 .NET、FFmpeg 或其他运行库，无需管理员权限。

开始使用
--------
1. 必须先把整个 ZIP 解压到一个普通文件夹；不要直接在压缩包预览窗口里运行。
2. 双击 DynamicWallpaperStudio.exe。
3. 第一次启动只打开管理界面，不会自动接管桌面。选中壁纸后点击“设为动态壁纸”，或点击顶部“启动动态壁纸”。
4. 如果上次异常退出，可双击“安全模式启动.cmd”；安全模式不会创建任何壁纸窗口。
5. 如果桌面显示异常，可双击“紧急关闭动态壁纸.cmd”，它会停止壁纸并用安全模式重新打开管理界面。
6. 关闭主窗口后壁纸仍会运行。可在 Windows 任务栏通知区域打开、暂停、切换收藏或退出。

如果 Windows 显示“Windows 已保护你的电脑”
--------------------------------------
这个预览版尚未购买代码签名证书，因此从网络下载后可能触发 Microsoft Defender SmartScreen。
确认 ZIP 来源正确后，点击“更多信息”，再点击“仍要运行”。

视频与空间
----------
• 兼容的 H.264 MP4 可选择“保持原始分辨率”：应用只记录原文件位置，不复制视频。
• 选择 1080p、2K、4K、匹配显示器或自定义尺寸时，只保存一份转换成品，不保存原片副本。
• 封面和转换成品位于程序目录下的 Data 文件夹。移动整个程序文件夹时，资料库会一起移动。
• 删除“引用原视频”的壁纸，只删除资料库记录和封面，不会删除你的原视频。
• 导出 .dwallpaper.zip 是你主动创建的便携副本，会额外占用空间。

长视频与性能
------------
视频按需解码，时长增加不会让整段视频进入内存。转换也采用流式处理。
4K、高帧率或同时在多块屏幕播放不同视频，仍会提高 CPU/GPU 使用率。

画面适配
--------
“完整显示”保持全部画面和比例，比例不同时会留边。
“填满屏幕”保持比例并铺满屏幕，可能裁掉少量边缘，不会拉伸人物。

开机启动
--------
在“设置”中开启“登录 Windows 时自动在后台启动”。如果之后移动了整个程序文件夹，请关闭后重新开启一次该选项，以更新路径。

便携数据与升级
--------------
Data 文件夹保存资料库、收藏和转换成品。升级时退出应用，用新版文件替换程序文件，但保留原 Data 文件夹。

预览版说明
----------
本包已在 macOS 构建机上完成 Windows x64 编译与静态文件校验，但尚未在真实 Windows 电脑上完成桌面层级、多屏和 Explorer 重启的运行验收。
如果出现壁纸在图标上方、黑屏或 Explorer 重启后未恢复，请先从通知区域退出应用，并把 Windows 版本与显示器排列反馈给开发者。

安全与兼容说明
--------------
本版本默认关闭动态壁纸，且只有在视频已经打开、桌面层附着成功后才显示窗口。失败时会恢复普通桌面，诊断日志位于 Data\Logs\latest.log。
1.0.4 更换为 mpv 原生播放内核，并修复 Windows 11 新桌面层下的首帧超时、4K 画面缩在左上角和混合 DPI 尺寸识别。播放器只有在确认首帧已呈现、画布尺寸与目标屏幕一致、桌面层级校验通过后才显示。

第三方组件
----------
本程序随附独立的 FFmpeg、ffprobe 与 mpv 可执行文件。许可证和源码信息见 LICENSES 文件夹。
