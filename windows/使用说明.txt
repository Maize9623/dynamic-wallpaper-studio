动态壁纸工作室 · Windows x64 便携兼容版 1.0.5
========================================

系统要求
--------
推荐 Windows 11、64 位 x86 电脑。普通消费版 Windows 10 22H2 已结束支持，仅提供尽力兼容，不作为正式支持目标。
便携包已包含 .NET 运行时，无需管理员权限。首次正常启动需要联网获取视频组件。

开始使用
--------
1. 必须先把整个 ZIP 解压到一个普通文件夹；不要直接在压缩包预览窗口里运行。
2. 双击 DynamicWallpaperStudio.exe。
3. 首次启动会询问是否下载 mpv 0.41.0 和 FFmpeg 9.0.1，下载量约 190 MB，建议预留 2 GB 空间。选择“是”后请等待进度完成。
4. 程序会在解压前核验固定 SHA-256；不匹配的文件会被丢弃。组件保存在程序旁的 tools 文件夹。
5. 第一次启动只打开管理界面，不会自动接管桌面。选中壁纸后点击“设为动态壁纸”，或点击顶部“启动动态壁纸”。
6. 如果上次异常退出，可双击“安全模式启动.cmd”；安全模式不会联网，也不会创建任何壁纸窗口。
7. 如果桌面显示异常，可双击“紧急关闭动态壁纸.cmd”，它会停止壁纸并用安全模式重新打开管理界面。
8. 关闭主窗口后壁纸仍会运行。可在 Windows 任务栏通知区域打开、暂停、切换收藏或退出。

首次联网与隐私
--------------
公开便携包不直接附带 mpv、FFmpeg 或 Vulkan Loader 二进制。首次正常启动会从以下固定上游地址下载：
• mpv 0.41.0：GitHub 官方 Release
• FFmpeg 9.0.1 Essentials：FFmpeg 官网列出的 Windows 构建站 gyan.dev
下载过程不会上传你的壁纸、资料库或使用数据。诊断日志可能记录本地视频路径，公开反馈前请先检查并遮盖私人信息。

如果 Windows 显示“Windows 已保护你的电脑”
--------------------------------------
这个预览版当前未使用 Authenticode 代码签名，因此从网络下载后可能触发 Microsoft Defender SmartScreen。
请只从项目 GitHub Release 获取 ZIP，并核对 Release 公布的 SHA-256。确认来源后，点击“更多信息”，再点击“仍要运行”。
Smart App Control 或企业安全策略可能不提供“仍要运行”。请不要为此关闭系统防护，可改为自行审阅并构建源码。

视频与空间
----------
• 兼容的 H.264 MP4 可选择“保持原始分辨率”：应用只记录原文件位置，不复制视频。
• 选择 1080p、2K、4K、匹配显示器或自定义尺寸时，只保存一份转换成品，不保存原片副本。
• 封面和转换成品位于程序目录下的 Data 文件夹。移动整个程序文件夹时，资料库会一起移动。
• 删除“引用原视频”的壁纸，只删除资料库记录和封面，不会删除你的原视频。
• 导出 .dwallpaper.zip 是你主动创建的便携副本，会额外占用空间。

长视频与性能
------------
视频按需解码，时长增加不会让整段视频进入内存。转换也采用流式处理。
4K、高帧率或同时在多块屏幕播放不同视频，仍会提高 CPU/GPU 使用率。

画面适配
--------
“完整显示”保持全部画面和比例，比例不同时会留边。
“填满屏幕”保持比例并铺满屏幕，可能裁掉少量边缘，不会拉伸人物。

开机启动
--------
在“设置”中开启“登录 Windows 时自动在后台启动”。如果之后移动了整个程序文件夹，请关闭后重新开启一次该选项，以更新路径。

便携数据与升级
--------------
Data 文件夹保存资料库、收藏和转换成品，tools 文件夹保存首次下载的视频组件。升级时退出应用，用新版文件替换程序文件，但保留原 Data 文件夹；删除 tools 后，下次启动会重新下载安装。

预览版说明
----------
本包已在 GitHub Actions 的 Windows x64 构建机上完成编译与静态文件校验，但尚未在所有真实 Windows 电脑上完成桌面层级、多屏和 Explorer 重启场景的运行验收。
如果出现壁纸在图标上方、黑屏或 Explorer 重启后未恢复，请先从通知区域退出应用，并把 Windows 版本与显示器排列反馈给开发者。

安全与兼容说明
--------------
本版本默认关闭动态壁纸，且只有在视频已经打开、桌面层附着成功后才显示窗口。失败时会恢复普通桌面，诊断日志位于 Data\Logs\latest.log。
1.0.4 更换为 mpv 原生播放内核，并修复 Windows 11 新桌面层下的首帧超时、4K 画面缩在左上角和混合 DPI 尺寸识别。1.0.5 增加首次运行的固定上游下载、SHA-256 校验与下载失败恢复。

第三方组件
----------
本便携包不直接随附 FFmpeg、ffprobe、mpv 或 Vulkan Loader 二进制，它们由用户首次运行时从固定上游地址下载。许可证和源码信息见 LICENSES 文件夹。
便携包包含 self-contained .NET 运行时，对应 Microsoft 许可证与第三方声明也位于 LICENSES 文件夹。
